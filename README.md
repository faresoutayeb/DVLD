# DVLD
🚗 DVLD – Driving &amp; Vehicle License Department Management System | A desktop application designed to automate and manage the driver's licensing lifecycle, from applicant registration and driving tests to license issuance and ongoing license management. 💻



## Project Overview

The DVLD (Driving & Vehicle License Department) is a desktop application designed to manage and automate driving license services. It provides an organized environment for handling applicants, driving license applications, tests, drivers, and different license-related operations.

The project was developed to simulate a real-world driving license management system while applying software engineering principles and advanced programming concepts.

## Key Features

- **People Management:** Add, update, search, and manage people's information.
- **Applications Management:** Create and manage driving license applications.
- **Driving Tests:** Schedule, manage, and record vision, written, and practical driving tests.
- **License Management:** Issue, renew, and replace driving licenses.
- **Drivers Management:** Manage registered drivers and their license history.
- **International Licenses:** Issue and manage international driving licenses.
- **Detained Licenses:** Manage detained licenses and their release processes.
- **Users & Permissions:** Manage system users, roles, and access permissions.

## Technologies Used

- C#
- .NET Windows Forms
- SQL Server
- ADO.NET
- Guna UI2
- T-SQL and Stored Procedures

## Project Architecture

The application follows a layered architecture to separate responsibilities and improve maintainability.

- **Presentation Layer:** Handles the user interface and user interactions.
- **Business Logic Layer (BLL):** Handles business rules and application operations.
- **Data Access Layer (DAL):** Handles communication with the SQL Server database.

## Advanced Concepts & Implementation

Throughout the project, several C# and .NET concepts were applied in practical scenarios:

- Object-Oriented Programming (OOP).
- Generics and Reflection.
- Delegates and Events.
- Multithreading and Asynchronous Programming.
- Bitwise Operations for permissions management.
- Password Hashing and Salting.
- Encryption and Windows Credential Manager.

## Database

The application uses SQL Server to store and manage its data. The database includes relational tables, constraints, relationships, and stored procedures to support the application's operations and maintain data integrity.

## Getting Started

4. Restore the provided database backup or execute the database scripts.
5. Build and run the application.
